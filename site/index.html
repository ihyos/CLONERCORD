Discord Components V2

Abandone os embeds arcaicos. Interfaces modernas, nativas e ricas utilizando ContainerBuilder, SectionBuilder e SeparatorBuilder.

Auto-Upload & Emojis Diretos

A IA faz upload dos emojis da biblioteca direto para o bot via API REST, sem links quebrados ou dependência de servidores de terceiros.

Repository Pattern & Anti-Timeout

Comece com JSON DB local e migre com zero esforço para Supabase/PostgreSQL. A IA aplica deferReply() de imediato contra o limite de 3s.

Fluxo Obrigatório

Como a IA é treinada para agir

1

Nome e Propósito do Bot

Define branding, presença oficial e o escopo funcional (tickets, moderação, pagamentos, lojas ou utilitários).

2

Idioma e Localização

Configura estritamente PT-BR ou Inglês para todas as interfaces, botões e respostas da aplicação.

3

Stack Tecnológica

TypeScript (discord.js v14+), JavaScript (Node.js), Python, Go ou Rust com bibliotecas modernas.

4

Emojis Personalizados Semânticos

Se habilitado, a IA envia os ícones ao bot e os usa estritamente pelo seu significado (Pix = ícone do Pix, etc.). Zero emojis Unicode genéricos.

5

Estratégia de Persistência

Inicie rápido com JSON DB desacoplado por Repository Pattern e migre suavemente para Supabase/PostgreSQL quando pronto para produção.
