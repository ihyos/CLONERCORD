## Installation via Command

### NPX (Recommended - Instant)
```bash
npx clonercord-discord-skill
```

### NPX + Full Local Emoji Pack Download
```bash
npx clonercord-discord-skill --download-emojis
```

### PowerShell (Windows)

```powershell
irm https://raw.githubusercontent.com/ihyos/CLONERCORD/master/install.ps1 | iex
```

### Bash (Linux / macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/ihyos/CLONERCORD/master/install.sh | bash
```

### Git Sparse-Checkout (Native)

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/ihyos/CLONERCORD.git
cd CLONERCORD
git sparse-checkout set skill.md "emojis discord"
```

## Overview

This skill governs every decision made by an AI agent when building, extending, or correcting a professional Discord bot using Discord Components V2 in any programming language (TypeScript, JavaScript, Python, Go, Rust, C#, etc.).
